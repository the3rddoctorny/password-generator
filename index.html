How to use this thing

This generator makes passwords from a word list so they’re easier to remember, while still meeting common “picky website” rules.

  • Mode: Use Word count for readable passwords (2–4 full words). Use Exact length when a site demands a specific length.
  • Digits/Symbols: Toggle Include digit and Include symbol. If symbols are on, choose the allowed symbol set.
  • Title Case & Separator: In Word count mode you can format words as RocketSilver and optionally add separators like Rocket-Silver-7!.
  • Generate: Click Generate or press Enter.
  • Copy: Click Copy or click the password itself to copy it. You’ll see “Copied!” confirmation.

Word list status is shown at the bottom (assets vs fallback). If it says fallback, your browser couldn’t load the external list.
